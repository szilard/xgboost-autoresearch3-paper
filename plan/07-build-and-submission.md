# 07. Build, repository layout, submission

## Repository layout (`xgboost-autoresearch3-paper/`)

```
plan/                 this plan (keep; it documents provenance)
analysis/             scripts of 03-data-and-analysis.md; run_all.sh; README.md (table/figure → script → output)
analysis/results/     committed printed outputs, one file per table or figure, command on line 1
figures/              generated PDFs and PNGs
paper/                the paper source
  paper.md            (option A) pandoc Markdown with YAML header, as the companion paper was written, or
  main.tex, sections/ (option B) plain LaTeX
  refs.bib            final bibliography (grown from plan/references.bib)
  header.tex          LaTeX preamble (fonts, hyperref, natbib or biblatex, float placement)
  Makefile            make pdf / make arxiv
README.md             what this is, how to build, licence, how to cite
LICENSE               CC BY 4.0 for the text and figures; MIT for the analysis scripts
```

The paper repo links to, and pins, `xgboost-autoresearch3` (`7e8bc23`),
`xgboost-autoresearch-minimal3-runs` (`b2841ab`) and `xgboost-autoresearch-minimal3` (`5fb023a`).

## Toolchain

Option A (recommended, matches the authors' previous workflow): pandoc Markdown → LaTeX → PDF.

```
pandoc paper/paper.md --from markdown --to latex --standalone --natbib \
  --include-in-header paper/header.tex --output paper/main.tex
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Option B: write `main.tex` directly with `\documentclass[11pt]{article}`, `geometry` (1 inch),
`natbib` (author-year, `plainnat`) or `biblatex`, `graphicx`, `booktabs`, `hyperref`,
`microtype`, and `\usepackage{times}` or `newtx` for a compact look. Single column.

Either way: figures as PDF; tables with `booktabs`; no `\clearpage` hacks until the end; let
floats float; `\appendix` for A to G.

## Writing steps and milestones

1. **M1 Decisions** (`08`): title, naming, citation style, optional analyses, categories.
2. **M2 Analysis**: implement `analysis/` scripts 1 to 8, run `run_all.sh`, commit `results/`.
   Compare with the verification table in `03`; any difference must be explained before writing.
3. **M3 Figures**: regenerate F1 to F4 as PDF; make F5 and F7 (F6, F8, F9 if chosen).
4. **M4 Methods and Results**: write from the outline with the tables in place.
5. **M5 Related work, Introduction, Discussion, Conclusion, Appendix**; verify the `TO VERIFY`
   bib entries; write the disclosure.
6. **M6 Abstract**, then the consistency pass of `06` (independent read; number check script:
   extract every 0.xxxx and every percentage from the `.tex` and look it up in `results/`).
7. **M7 arXiv**: see checklist. Record the arXiv id in the blog post's README and in the three
   repos' READMEs; add a "How to cite" block.

## arXiv submission checklist

- Primary category `cs.LG`; cross-list `cs.AI` and `stat.ML` (possibly `cs.SE`); decide in `08`.
- Licence: CC BY 4.0.
- Upload the LaTeX source: `main.tex`, `main.bbl` (arXiv runs pdflatex but needs the `.bbl`),
  `header.tex` if separate, the figure PDFs; `\pdfoutput=1` in the first 5 lines of `main.tex`.
- Abstract in the metadata: plain text, under 1,920 characters, no Markdown, no line breaks inside
  paragraphs; the title in title case; author names exactly as on the blog and the companion paper.
- Comments field: "N pages, M figures. Code and data: github.com/szilard/xgboost-autoresearch-minimal3-runs".
- Check the compiled PDF on arXiv's preview: fonts embedded, figures not rasterised, hyperlinks
  work, appendix tables fit the page (use `\small` and `longtable` or split T9 by LLM).
- After announcement: update the blog post with the arXiv link; tag the three repos.

## Build checks to automate

- `make check-numbers`: every number in the `.tex` that looks like an AUC (0.6xxx), a difference
  (±0.00xx), a percentage, or a minute count must be found in `analysis/results/`.
- `make check-bib`: every `\cite` key exists; every bib entry is cited; no `TO VERIFY` notes
  remain.
- `make check-figures`: every figure file referenced exists and was regenerated by `make_figures.py`
  after the last change to `results/`.
